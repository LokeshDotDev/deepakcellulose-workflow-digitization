# DEEPAK CELLULOSE ERP — CRUD & DATA LIFECYCLE COVERAGE MATRIX

> **Standard**: ALCOA+ Data Integrity, GMP (Good Manufacturing Practice), 21 CFR Part 11  
> **Policy on Deletion**: Regulated manufacturing records (issued purchase orders, posted inventory movements, analytical test results, release notes, batch records, dispatches, and invoices) **must never be physically deleted**. Corrections are achieved via controlled reversals or compensating ledger transactions that preserve complete audit history.

---
